# Voice Dicto

Веб-версия голосовой диктовки в духе [VoiceInk](https://github.com/Beingpax/VoiceInk) / Handy: запись голоса
в браузере → распознавание речи (STT) → очистка текста от слов-паразитов и повторов через LLM (Enhance) →
готовый текст для копирования. Полностью статический сайт, деплоится на GitHub Pages, без своего сервера.

## Как это работает

1. **Запись** — `MediaRecorder` пишет звук с микрофона прямо в браузере.
2. **Распознавание речи** — аудио отправляется в облачный STT-провайдер (Groq Whisper или Gemini),
   выбранный в настройках.
3. **Очистка (Enhance)** — сырой текст прогоняется через LLM с одним из пресетов:
   - **Просто почистить** — убрать "э-э", "короче", "как бы", повторы и самоисправления, не меняя смысл;
   - **Деловое письмо** — та же чистка + вежливый деловой тон;
   - **Заметка/тезисы** — сжать в короткие пункты;
   - **Свой промпт** — произвольная инструкция.
4. Результат показывается на экране и копируется в буфер обмена одной кнопкой.

## Ключи API — где взять и как они хранятся

Приложение работает с вашим личным бесплатным ключом одного из провайдеров:

- **Groq** (рекомендуется, быстрее всего) — бесплатный ключ на [console.groq.com/keys](https://console.groq.com/keys).
  STT: `whisper-large-v3-turbo`. Enhance: `openai/gpt-oss-20b`.
- **Google AI Studio (Gemini)** — запасной вариант, бесплатный ключ на
  [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey). Модель: `gemini-2.0-flash`.

Ключ вводится один раз в настройках приложения (⚙) и хранится **только в `localStorage` вашего браузера**.
Он уходит напрямую из вашего браузера к API провайдера и никогда не попадает в код репозитория, в
сборку сайта или к другим посетителям — это личный инструмент одного пользователя, а не публичный сервис
с общим ключом. Кнопка «Очистить сохранённые ключи» в настройках удаляет их из `localStorage`.

## Ограничения

- **Нет глобального системного хоткея.** В отличие от нативных VoiceInk/Handy, это обычная веб-страница:
  запись работает только пока вкладка открыта и активна.
- **Публичный статический сайт.** Любой, кто знает адрес, может открыть страницу — но без собственного
  API-ключа она бесполезна (транскрипция не заработает).
- **Бесплатные лимиты провайдеров** рассчитаны на личное использование одним человеком, а не на публичный
  сервис для многих пользователей одновременно.
- Пока реализован только облачный трек (Groq/Gemini). Полностью локальный офлайн-режим
  (WebGPU Whisper + WebLLM в браузере, без ключей и без сети) — в планах, см. «Дальнейшее развитие».

## Разработка

```bash
npm install
npm run dev
```

## Деплой на свой GitHub Pages

1. Форкните/склонируйте репозиторий.
2. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
3. Запушьте в ветку `main` — workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт.
4. Если имя репозитория отличается от `voice-dicto-web`, поправьте `base` в `vite.config.ts`
   на `/<имя-вашего-репозитория>/`.

## Дальнейшее развитие

- Полностью локальный трек: транскрипция через `@huggingface/transformers` (WebGPU/WASM) и очистка через
  `@mlc-ai/web-llm` — без ключей и без сети, но медленнее и тяжелее при первой загрузке моделей.
- PWA + офлайн-кэш локальных моделей.
- Персональный словарь терминов, которые LLM не должна коверкать.
- Экспорт истории в файл.
- Браузерное расширение как способ обойти отсутствие глобального хоткея.
