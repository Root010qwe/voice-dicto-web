# Voice Dicto

Веб-версия голосовой диктовки в духе [VoiceInk](https://github.com/Beingpax/VoiceInk) / Handy: запись голоса
в браузере → распознавание речи (STT) → очистка текста от слов-паразитов и повторов через LLM (Enhance) →
готовый текст для копирования. Полностью статический сайт, деплоится на GitHub Pages, без своего сервера.

## Как это работает

1. **Запись** — `MediaRecorder` пишет звук с микрофона прямо в браузере.
2. **Распознавание речи** — аудио отправляется в Groq Whisper через встроенный ключ, без какой-либо
   настройки со стороны пользователя.
3. **Очистка (Enhance)** — сырой текст прогоняется через LLM с одним из пресетов:
   - **Просто почистить** — убрать "э-э", "короче", "как бы", повторы и самоисправления, не меняя смысл;
   - **Деловое письмо** — та же чистка + вежливый деловой тон;
   - **Заметка/тезисы** — сжать в короткие пункты;
   - **Свой промпт** — произвольная инструкция.
4. Результат показывается на экране и копируется в буфер обмена одной кнопкой.

## Ключи API — где взять и как они хранятся

⚠️ **Изменение модели безопасности.** Изначально это приложение проектировалось так, чтобы ключ
никогда не попадал в код репозитория. По прямому запросу владельца проекта в `src/config/defaultKeys.ts`
теперь **вшит рабочий ключ Groq**, чтобы сайт работал сразу, без ручной настройки. Это осознанный
компромисс ради удобства одного конкретного пользователя, а не рекомендуемая практика:

- Ключ виден любому посетителю сайта (через просмотр кода страницы, вкладку Network или сам исходник
  на GitHub) и **постоянно хранится в истории git**, даже если его потом удалить из последнего коммита.
- Публичные ключи в открытых репозиториях обычно находят автоматические сканеры в течение часов/дней и
  используют чужую квоту — стоит быть готовым, что встроенный ключ рано или поздно перестанет работать
  (лимит, бан) без предупреждения.
- Если вы форкаете этот репозиторий — **замените ключ в `defaultKeys.ts` на свой** (или очистите поле)
  до публикации, иначе унаследуете этот же риск с чужим ключом.

В интерфейсе нет настроек и нет поля для ввода своего ключа — единственный способ использовать
личный ключ вместо общего сейчас — отредактировать `src/config/defaultKeys.ts` в своей копии
репозитория и задеплоить форк. Бесплатный ключ Groq — на
[console.groq.com/keys](https://console.groq.com/keys) (STT: `whisper-large-v3-turbo`, Enhance:
`openai/gpt-oss-20b`); в коде также есть готовый провайдер Gemini (STT и Enhance через
`gemini-2.0-flash`, ключ на [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey))
на случай проблем с Groq, но по умолчанию используется только Groq.

## Ограничения

- **Нет глобального системного хоткея.** В отличие от нативных VoiceInk/Handy, это обычная веб-страница:
  запись работает только пока вкладка открыта и активна.
- **Общий встроенный ключ.** Сайт работает «из коробки» для любого посетителя, но именно поэтому его
  бесплатная квота общая на всех и может закончиться в любой момент — см. предупреждение выше.
- **Бесплатные лимиты провайдеров** в целом рассчитаны на личное использование одним человеком, а не на
  публичный сервис для многих пользователей одновременно.
- Пока реализован только облачный трек (Groq/Gemini). Полностью локальный офлайн-режим
  (WebGPU Whisper + WebLLM в браузере, без ключей и без сети) — в планах, см. «Дальнейшее развитие».

## Разработка

```bash
npm install
npm run dev
```

## Деплой на свой GitHub Pages

1. Форкните/склонируйте репозиторий.
2. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
3. Запушьте в ветку `main` — workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт.
4. Если имя репозитория отличается от `voice-dicto-web`, поправьте `base` в `vite.config.ts`
   на `/<имя-вашего-репозитория>/`.

## Дальнейшее развитие

- Полностью локальный трек: транскрипция через `@huggingface/transformers` (WebGPU/WASM) и очистка через
  `@mlc-ai/web-llm` — без ключей и без сети, но медленнее и тяжелее при первой загрузке моделей.
- PWA + офлайн-кэш локальных моделей.
- Персональный словарь терминов, которые LLM не должна коверкать.
- Экспорт истории в файл.
- Браузерное расширение как способ обойти отсутствие глобального хоткея.
